# หมวดหมู่คำศัพท์มาตรฐาน

ใช้ความหมายหลักและชนิดคำจากพจนานุกรมเป็นเกณฑ์ ไม่จัดหมวดจากคำที่ปรากฏเพียงในตัวอย่างประกอบ

- อาหารและเครื่องดื่ม
- พืชและเกษตร
- สัตว์
- บุคคลและเครือญาติ
- สถานที่และชุมชน
- ศาสนาและความเชื่อ
- ภาษาและอักษร
- ร่างกายและสุขภาพ
- ธรรมชาติและสิ่งแวดล้อม
- สิ่งของและเครื่องมือ
- ศิลปะ ดนตรี และการละเล่น
- การกระทำ
- ลักษณะและอาการ
- เวลาและจำนวน
- คำไวยากรณ์และคำเชื่อม
- คำศัพท์ทั่วไป

สถานะหมวดหมู่:

- `proposed`: เสนอด้วยกฎอัตโนมัติ ยังไม่ถือว่ายืนยัน
- `source_reviewed`: ผู้ตรวจอ่านความหมายจากภาพแหล่งข้อมูลแล้ว
- `expert_verified`: ผู้เชี่ยวชาญ/เจ้าของข้อมูลยืนยันแล้ว
